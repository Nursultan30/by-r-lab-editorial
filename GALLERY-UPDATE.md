# Обновление журнальной галереи By_R.Lab

- Галерея — вторая секция, непосредственно после неизменённого Hero.
- Семь основных разделов: Hero → галерея → мануфактура → услуги → процесс → сотрудничество → FAQ/контакты. Полезные старые блоки и anchor ID сохранены внутри соответствующих разделов.
- Первые два изображения — крупные вертикальные рядом; третье — новый горизонтальный AI-кадр. После него — CTA «Обсудить пошив своей коллекции». Далее асимметричная сетка и дополнительные ракурсы.
- 35 самостоятельных образцов из 33 исходных карточек. По прямому ответу пользователя две пары разделены: светлый/пудровый твид и синий/бежевый корпоративный поло. Различия не выдаются за подтверждённые варианты цвета.
- Переключатели цветов реализованы и проверены на контролируемом тестовом наборе с `variants_confirmed: true`. В фактическом наборе они не включены, поскольку пользователь пока не подтвердил группы.
- Полноэкранный native dialog: предыдущий/следующий снимок, миниатюры, оригиналы, Escape, стрелки клавиатуры, свайп, возврат фокуса и запрос в WhatsApp.
- Заголовки и описания изделий взяты из JSON архива; торговая корзина, наличие и цены в галерею не добавлялись.
- GSAP ScrollTrigger деликатно раскрывает фото через маски на desktop. На узких экранах и при reduced motion анимации галереи отключены; фото видимы без GSAP.
- Сохранены боковые швейные линейки, контакты, FAQ, форма WhatsApp, услуги и актуальные ссылки.

## Фотографии

Создано 18 новых отдельных AI-кадров: 9 замен коллажных кропов, 6 недостающих основных фото, 2 кадра для разделённых образцов и 1 широкий разворот. Это **не серия из 50 новых AI-фотографий**. В галерее подключены 36 индивидуальных AI-файлов (35 основных + широкий разворот) и 44 оптимизированных оригинальных снимка для сравнения. Все 50 оригиналов остаются в полученном исходном архиве; в web-пакет включены используемые оптимизированные копии.

AI-фотографии — редакционные визуализации на основе исходников. Они визуально сверены по общему крою, цвету, воротникам, пуговицам и отделке, но не являются документальным подтверждением точности ткани, вышивки, всех швов и фирменных знаков. У бежевого поло отдельно исправлен добавленный генерацией нагрудный карман. Точность логотипа Helios нужно оценивать по оригиналу, доступному в просмотре. Автоматическое увеличение черновых кропов не использовалось.

Документы архива содержат отчёты разных итераций с несовпадающими цифрами. Для этой версии использованы фактические данные `gallery-data.json`, `UPDATED_MANIFEST.json` и проверка файлов. Файл CODEX_PROMPT.md не использовался как отдельное разрешение на публикацию или изменение других проектов.

## Проверки

- 360 / 390 / 430 / 768 / 1024 / 1440 / 1920 px: нет горизонтального переполнения и выхода заголовков.
- Все 6 категорий и «Все работы» фильтруют корректно.
- Все 80 ссылочных файлов галереи отвечают успешно.
- Полноэкранный просмотр, оригиналы, стрелки, Escape и возврат фокуса проверены в Chromium.
- Reduced motion: opacity 1, clip-path none, анимаций на изображениях нет.
- Меню, раскрытие услуги, FAQ, все якоря и формирование ссылки WhatsApp проверены. Сообщение не отправлялось.
- DOM Hero совпадает с предыдущей опубликованной версией.

Проверки выполнялись в локальном Chromium / Playwright. Физические iOS/Android и Safari не проверялись. Preview на Vercel защищён входом; статус публикации и соответствие исходников проверяются через Vercel API. Production не обновляется без отдельного разрешения.

## Файлы

`src/gallery/gallery-data.json` — единый источник карточек; `gallery-data.js` — его статическая сериализация. `editorial-gallery.js` и `editorial-gallery.css` — изолированный компонент. Оригинальный компонент из ZIP адаптирован к существующему сайту, а не заменил его целиком.

Для повторения проверок установите Playwright в локальное окружение, затем выполните `BASE_URL=http://localhost:8765/ node qa/gallery-qa.cjs` и `BASE_URL=http://localhost:8765/ node qa/gallery-supplement.cjs`. Сборка сайта: `npm run build`.

# By_R.Lab — editorial redesign preview

Изолированная переработка существующего проекта `by-r-lab`. Production не публикуется автоматически.

## Запуск и сборка

- Node.js 20+.
- `npm run build` копирует статический сайт в `dist/`.
- Для просмотра используйте любой локальный HTTP-сервер, раздающий `dist/`.
- Никакой миграции на React / Next.js, базы данных и переменных окружения не требуется.
- GSAP 3.14.2, ScrollTrigger и Flip включены локально в `src/vendor/`; шрифты загружаются с Google Fonts, имеются системные fallback.
- GSAP распространяется на условиях Standard License: https://gsap.com/standard-license/ .

## Дизайн-система

Fashion Editorial × Swiss Minimalism. Белые поля, нейтральные поверхности, большие фотографии, тонкие линии, технические подписи, прямоугольные CTA с SVG-стрелками.

- `--color-primary: #CF6444`
- `--color-accent: #CF6444`
- `--color-background: #FFFFFF`
- `--color-surface: #F4F4F1`
- `--color-text: #242522`
- `--color-muted: #6C6D68`
- `--color-border: #DDDED8`
- `--color-milk: #EFECE7`

**Ограничение брендинга:** #CF6444 — фактически измеренный наиболее частый красно-оранжевый пиксель прежнего `assets/byrlab-logo.png` (RGB 207,100,68). Его тёплый фон — #EFECE7. Остальные интерфейсные нейтрали выбраны для макета, это не извлечённые из нового логотипа цвета. Новое изображение логотипа видно в переписке, но его бинарный файл не был предоставлен рабочему окружению. Поэтому текущий акцент временный; точные HEX нового изображения и замена логотипа остаются незавершёнными. Мы не выдаём визуальную оценку цвета за измерение.

Типографика: Inter 400 для крупных заголовков; Manrope для основного текста; JetBrains Mono для технических подписей. Размеры адаптируются через clamp и медиазапросы. Основной текст 12–15 px в зависимости от элемента, заголовки 35–142 px; технические подписи меньше и не несут единственную копию существенной информации.

## Секции и взаимодействия

1. Hero: раскрытие строк, zoom-out фото, последовательное появление CTA.
2. Практика / галерея: горизонтальная лента, категории, стрелки, клавиатура, нативный touch-scroll, mouse drag, GSAP Flip при фильтрации.
3. Малый тираж: крупное фото и текстовые аргументы, image mask reveal.
4. Для кого: два исходных сегмента аудитории.
5. Производство: исходные факты команды и текущий логотип.
6. Услуги: раскрытие по кнопке с `aria-expanded`, описание и WhatsApp CTA.
7. Категории: сохранённая вторая галерея, ручные вкладки, стрелки и свайп.
8. Конструкторское бюро: лёгкий parallax изображения.
9. Процесс: шесть исходных этапов, sticky-фото на desktop, динамический номер, SVG-выкройка с прорисовкой.
10. Качество: исходная иллюстрация и аргументы.
11. Цены: стабильные значения без автоматического мерцания валют.
12. География: Кыргызстан / Казахстан.
13. FAQ: нативные details / summary.
14. Бриф: форма, которая открывает WhatsApp и ничего сама не отправляет.
15. Финальный CTA и контакты.

Курсор «Смотреть / Листать» и magnetic CTA включаются только для fine pointer. При reduced motion эффекты, marquee, parallax и custom cursor отключены. Все тексты видимы без GSAP. Переходы между страницами не добавлялись: сайт одностраничный. Lenis не используется, нативная прокрутка сохранена.

Автопрокрутка заменена ручным просмотром, чтобы посетитель мог изучить изделия; все способы ручного переключения сохранены.

## Границы проверки

Проверки выполняются в Chromium / Playwright; Safari и физические iOS/Android устройства не проверялись. Отправка сообщения в WhatsApp не выполняется: проверяется корректное формирование URL, номера и текста. Скорость загрузки и Lighthouse не измерялись. Фотографии сохранены в исходном качестве; некоторые исходники имеют небольшое разрешение.
